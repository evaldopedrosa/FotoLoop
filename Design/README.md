# FotoLoop design assets

- `FotoLoop-AppIcon-1024.png`: 1024 × 1024 reference image.
- `FotoLoop-iconset.zip`: editable icon size package.
- `FotoLoop.icns`: macOS icon copied into the app bundle by the build script.

These files are part of the public source repository. The app uses `FotoLoop.icns`; changing the artwork does not require changing the app architecture.
